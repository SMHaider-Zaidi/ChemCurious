## 📖 Overview

**ChemCurious** is an advanced interactive platform engineered for real-time spatial chemistry visualization, chemical reaction modeling, and elemental breakdown. Designed to bridge the gap between static chemical formulas and dynamic physical structures, the system translates spatial atomic coordinates, bond geometries, and reaction pathways into high-fidelity, interactive 3D models.

---

## ✨ Core Features

### 🧊 3D Molecular Spatial Renderer
* **Precision Ball-and-Stick Modeling:** Renders real dynamic 3D molecular structures using exact Ångström spatial coordinates ($x, y, z$).
* **Structural & Orbital Fidelity:** Accurately represents bond orders (single, double, triple) and spatial geometries (tetrahedral, trigonal planar, linear).
* **Full Camera Control:** Smooth WebGL viewport controls allowing users to orbit, rotate, pan, zoom, and inspect spatial atom-to-atom relationships in real time.

### ⚛️ Interactive Periodic Table Engine
* **Comprehensive Elemental Dataset:** Interactive access to all 118 elements with instant search and filtering.
* **Deep Property Inspection:** Provides detailed breakdowns per element, including atomic mass, electronic configuration, electronegativity, atomic radius, and category classification.

### ⚗️ Chemical Reaction Engine
* **Transformation Pipelines:** Searchable catalog spanning over 270 chemical reactions.
* **Dynamic Mapping:** Instantly visualizes reactant-to-product pathways, structural transformations, stoichiometry, and underlying chemical properties.

### 📊 Robust Structural Database Engine
* **Normalized Data Architecture:** Scalable schema designed to store molecular formulas, structured JSON coordinate payloads, multi-step reaction sequences, and compound classifications.
* **Automated Integrity Auditing:** Dedicated scripting pipelines that validate atomic coordinate structures, clean chemical payloads, and handle data seeding across hundreds of complex compounds.

### 📝 Interactive Quiz Engine
- **Linear Step-by-Step Testing:** Single-question focus with real-time response validation and automated scoring to prevent backtracking and maintain quiz integrity.
- **Chapter-Wise Evaluation:** Target specific topics across general, organic, and inorganic chemistry with custom difficulty levels.

### 📈 Student Performance Dashboard
- **Comprehensive Analytics:** Tracks completed quiz history, average scores, and percentage badges directly linked to student accounts.
- **Targeted Insights:** Highlights topic mastery and performance metrics to help students identify strengths and areas for revision.
